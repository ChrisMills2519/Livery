# Groom prop library

Low-poly farm and horse props, generated procedurally by
[`tools/build_props.py`](../../tools/build_props.py). Everything is flat shaded and
uses solid Blender materials — no textures, no UVs, no external assets — so the props
import cleanly into Godot and stay cheap on the Compatibility renderer and the tablet
build.

| `garden/` | 4 | chicken coop, beehive, fence panel, farm gate |
| `course/` | 2 | jump wing, striped jump pole |
| `grooming/` | 7 | curry comb, dandy brush, soft brush, face brush, hoof pick, sponge, sweat scraper |
| `crowd/` | 6 | three seated spectators, a child, two standing spectators, for the showground grandstand |
| `arena/` | 2 | judge's bell, showground entrance arch |

Each GLB holds a single object, one metre = one Blender unit, origin on the ground
(0, 0, 0) and no transform baked into the object. `props_manifest.json` lists every
prop with its category, bounding size in metres, triangle count and material slots.

The stable yard and the forest/nature scatter are generated by
[`tools/build_scenery.gd`](../../tools/build_scenery.gd); edit the tables there and
re-run it rather than moving instances by hand. The farmhouse interior keeps the
Kenney furniture kit and the grooming bay is anchor-driven, so neither takes these
props.

## Browsing and editing in Blender

`artifacts/props_library.blend` contains the whole library laid out in a labelled
grid, one collection per category (`props_trees`, `props_stable`, …). Each object is
marked as an asset, so with the file open you can reach the props from
**Asset Browser → Current File** and drag them straight into a scene (they land at
the cursor). The objects in the grid keep their layout position, so use the GLBs or
the Asset Browser when you want a prop at the origin. The sheet renders are in
`artifacts/props_<category>.png` and `artifacts/props_overview.png`.

## Rebuilding

```bash
blender --background --factory-startup --python tools/build_props.py
blender --background --factory-startup --python tools/build_props.py -- --stage trees
```

The first rewrites every GLB, the manifest, the `.blend` and the contact sheets; the
second rebuilds a single category while iterating. Props are plain `bmesh` primitives
inside small builder functions, so adding one means writing a `Prop` builder, calling
it from the matching `build_<category>()` and naming it in `CATEGORY_ORDER`'s
category if the category is new.

## Using them in Godot

Drop a GLB into a scene; it imports as a `PackedScene` with the mesh and its
materials. The props are authored at real-world scale, so a 1.8 m rider, a 1.6 m
trough and a 1.1 m hay bale line up without rescaling. Enable shadow casting on the
instanced meshes — the geometry is closed and cheap (about 37k triangles for the
whole library, 78 props).
